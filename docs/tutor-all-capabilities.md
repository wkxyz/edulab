# edulab 六类能力接入

本次按用户要求将 upstream wy51ai/edulab@805fdc5dd6bdf942290a7791924bf0ee08f26632 的六个模块接入同一网站。上游技能文件保持原样，网站适配器使用受限 JSON 驱动可信引擎，禁止模型提供可执行代码。

| 模块 | 网站输入 | 产物与操作 |
| --- | --- | --- |
| 立体几何 | 文字、题图、内置例题/随机练习 | 精确向量内核、可旋转3D模型、逐步讲解、独立HTML |
| 解析几何 | 文字、题图、内置例题/随机练习 | 圆锥曲线、参数滑块、范围/定值读数、独立HTML |
| 化学反应 | 文字、题图、内置例题/随机练习 | 配平、原子映射与守恒、3D反应进度、独立HTML |
| 数学视频 | 文字、题图、内置例题 | 四类板书/手绘、图形动作、配音网页预览、SRT、MP4 |
| 物理视频 | 文字、题图、内置例题 | 受力、运动与图示、配音网页预览、SRT、MP4 |
| 化学视频 | 文字、题图、内置例题 | 配平/守恒、电子桥、三段式/粒子图示、配音网页预览、SRT、MP4 |

## 任务与兼容

capability 指定六类之一，旧请求默认数学视频。sampleId=default 使用当前模块内置示例，交互模块的 random 使用真实内置题型生成，不冒充用户任意题目的解答。文字与图片通过同一求解/原题独立复核流程。

视频 exportVideo=false 可先生成网页预览和配音；随后 POST /api/tasks/:id/export 创建无模型/无TTS调用的渲染任务，复用原文件。重复导出同一来源复用已有导出记录，不重置原任务 attempts/calls/requests，也不自动重试。原先已完成的视频继续可读。

公开媒体仅允许固定文件名和当前任务媒体凭证。HTML独立内联可信依赖、字体和音频，禁止外连；网页预览放在仅允许脚本的隔离iframe，不授予同源权限。下载HTML可脱离服务器打开。数学曲线与解析图形中的算式经有限算术解析器检查；模型不能提供Python、JavaScript、URL或任意本地路径。

## 支持范围

- 立体几何支持正方体、长方体、正四棱锥、正四面体的线面角、线线角、点面距离、二面角和体积，以及有界中点/比例点。上游说明中的柱锥全部种类并没有对应精确内核，未宣称任意几何题都可解。
- 解析几何支持经过椭圆/圆内部点的已验证弦长和数量积范围、中心弦面积范围、对称点斜率积、焦点弦抛物线定值，以及受限双曲线离心率族。未证明的参数范围明确返回不支持。
- 化学3D反应使用上游有限物种库和守恒检查；酯化使用可信固定机理例。动画是教学示意，不能替代真实分子动力学。
- 三类视频使用真正的上游 handdrawn/physics/chemistry 引擎和固定数据分发器。支持有界图形、平移/旋转、匀加速/圆周/简谐运动、光线/场、化学守恒/计量等；不执行任意每题编程代码。
- MiniMax仍执行求解和独立原题复核；中文语音使用既有独立Key。真实句长由实际音频决定，未声称逐字时间戳同步。
