# 分步讲解与20元累计预算

当前改动通过codex/lesson-first-budget20向main提交PR。以下描述实现行为，是否已正式发布以main自动部署及公网验收为准。

## 学习流程

- 默认生成文字步骤及适用的交互/无声演示，不自动合成配音或导出MP4。
- 完成后点击“生成配音讲解”，复用原题、已核对答案和保存的讲解；不再次求解。三类交互页面转换为显示完整原题、步骤和答案的配音板书。
- 配音先提供HTML播放；需要文件时再点击“导出 MP4 视频”。导出复用音频，重复点击返回同一任务，不增加模型/配音调用。
- 老视频和已配音网页继续可读。派生任务保留来源链接；失败不自动付费重试。

## 预算含义

本轮上限为2000人民币分（20元），是项目累计准入预留，跨日和重启不重置。解答默认预留100分、配音200分，分别记录次数，并共同受总额控制；MP4只占渲染资源。预留不等于实际供应商账单，也不是供应商的硬扣费上限。

历史两个真实任务仍各保留1000分，合计2000分，因此按现有记录没有可直接承诺的新付费余额。不能为继续测试就删除历史、把预留当实际消费，或自行将失败任务退款。须先核对供应商已发生费用并形成可审计的结算记录，再在同一20元范围内决定实际验收额度。

新阶段次数默认0，LIVE_ENABLED及私有配置不自动改动。样例使用离线音频，不占付费额度，但仍受项目资源上限。开发及CI禁止真实供应商调用。

## 发布与验收

仓库原来默认master且无main；已以原master805fdc5建立main基线，本轮工作从main开分支并纳入已有网站实现。所需CI通过且main自动部署入口核实后才合并。不得使用此前手工升级/追加额度脚本绕过main发布流程。

本轮尚未核实main自动部署和Grok Bot合并通知的真实配置；不能以“已有CI检查”推断已具备自动发布。暂不能合并时，返回PR链接供用户转PO。PR合并后的PO验收通知由既有Grok Bot流程负责，不另外发送消息。

验收须覆盖：六类无声讲解、显式配音、音频播放/定位、图形交互、MP4播放/206范围下载、重复生成幂等、来源所有权、累计预算跨日/重启、停止和取消。隔离模拟成功不等于真实供应商质量验收。
