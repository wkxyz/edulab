# 题解首版验收记录

## 实现与限制

- 网站：同源原生 HTML/CSS/JavaScript，复用已验证的网页客户端，适配手机与电脑；根据用户最新要求移除小程序交付。
- 服务：单实例 Node24 + SQLite，保留 edulab 原技能，通过声明式板书适配器调用。
- 真实接口：图文题输入 → KIE Gemini求解 → 结合原题独立复核 → KIE ElevenLabs配音 → edulab/Chromium/ffmpeg；默认关闭，未用真实密钥进行端到端验证。
- 示例接口：明确标注固定方程，离线配音，生成实际 MP4。图片上传不会落到示例分支。
- 尚未完成：正式账号与支付、复杂图形题质量、真实模型单价/效果校验、公网 HTTPS 部署。Docker 文件已准备，尚未在实际主机构建验收。

## 行为与费用检查

| 场景 | 检查内容 |
| --- | --- |
| 重复/跨设备 | 幂等提交一次，不能读或取消他人任务；项目额度跨设备生效 |
| 重启 | SQLite 保存任务、每日用量、预算预留、停止状态；运行中任务终结，不自动付费重试 |
| 空队列/持续失败 | 无任务不继续调度；失败只执行一次 |
| 动态队列 | 一批执行过程中新增任务不再卡在队列尾部 |
| 上限 | 每日20题、每设备5题、总200题、队列10、串行1；每题收费生成最多14次，总HTTP请求最多171次 |
| 预算 | 每题预留超出项目预算时拒绝；重启不清零；不是供应商硬封顶 |
| 停止与恢复 | 停止阻断新任务/业务读取/后续调用，取消当前执行；管理接口鉴权；恢复不重做终态任务 |
| 渲染取消 | 浏览器启动和就绪等待也响应取消；延迟启动成功的浏览器仍会关闭 |
| 原题复核 | 将用户原始文本和原图交给复核，防止只验证模型改写后的另一道题 |
| 客户端会话 | 并发首次请求只创建一个会话，避免记录因令牌覆盖丢失 |

独立代码审查发现队列尾部滞留、渲染等待取消不及时、复核遗漏原始文本，均补充回归测试并修复；另修复浏览器首次会话竞争。

## 可复现验证

初版网站在本地通过20项检查、在GitHub隔离环境通过21项检查，包含真实HTTP与管理开关；KIE适配后的最新结果见下方补充。检查命令和部署步骤见 [tutor-quickstart.md](tutor-quickstart.md)。所有自动化验证使用固定示例或模拟供应商，付费 API 调用数为0。

初版网站通过记录：[Actions 40053673495](https://github.com/wkxyz/edulab/actions/runs/40053673495)，验证代码提交 `2a9819fa25de3f5e72545e964fae89f0773694fb`。流程为“真实图片上传明确拒绝未开通服务 → 示例取消 → 新示例完成 → 刷新任务链接 → 播放视频 → 浏览器后退”，视频41.701秒、1280×720，包含音视频轨，实际播放进度大于1秒，HTTP范围下载206，页面脚本错误0，付费调用0。放大后的板书与字幕也通过此轮生成、排版检查和播放验证。

本机环境禁止监听端口和启动 Chromium，使用已授权的 GitHub 标准 runner 上的 Playwright 进行实际浏览器验证；没有绕过沙箱。概念图与最新网页截图已逐项通过 `view_image` 对照：文案、层级、字体、颜色、相机与导航、布局和留白。新增答案/示例披露/取消入口为明确功能需要；生成状态显示真实步骤，视频帧来自实际引擎而非概念图。首轮发现移动端板书太小，已放大板书和字幕，并在渲染前拒绝引擎报告的文字溢出。
