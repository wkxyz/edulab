## 行为与费用检查

| 场景 | 检查内容 |
| --- | --- |
| 重复/跨设备 | 幂等提交一次，不能读或取消他人任务；项目额度跨设备生效 |
| 重启 | SQLite 保存任务、每日用量、预算预留、停止状态；运行中任务终结，不自动付费重试 |
| 空队列/持续失败 | 无任务不继续调度；失败只执行一次 |
| 动态队列 | 一批执行过程中新增任务不再卡在队列尾部 |
| 上限 | 每日20题、每设备5题、总200题、队列10、串行1；每题收费生成最多14次，总HTTP请求最多171次 |
| 预算 | 每题预留超出项目预算时拒绝；重启不清零；不是供应商硬封顶 |
| 停止与恢复 | 停止阻断新任务/业务读取/后续调用，取消当前执行；管理接口鉴权；恢复不重做终态任务 |
| 渲染取消 | 浏览器启动和就绪等待也响应取消；延迟启动成功的浏览器仍会关闭 |
| 原题复核 | 将用户原始文本和原图交给复核，防止只验证模型改写后的另一道题 |
| 客户端会话 | 并发首次请求只创建一个会话，避免记录因令牌覆盖丢失 |

独立代码审查发现队列尾部滞留、渲染等待取消不及时、复核遗漏原始文本，均补充回归测试并修复；另修复浏览器首次会话竞争。
