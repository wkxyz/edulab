# 拍题视频讲解首版设计

目标：在 wkxyz/edulab 的讲题引擎上增加响应式网站和服务端，使用户拍摄或上传一道题，得到分步、带配音的视频讲解。学段不设硬限制，优先验证小学和初中数学。

## 已选方案

用户于2026-10-24明确改为先做网站，不再推进小程序。沿用已经验证的 edulab 渲染服务，将网页客户端作为正式首版交付。采用同源原生 HTML/CSS/JavaScript + Node24 服务，不依赖小程序 AppID、uni-app 构建或微信登录。

## 首版交付

- 在独立分支增加代码，保留原始 skills 和许可证；不合并 master，不公开部署服务。
- 网站适配手机与电脑，提供上传、任务、历史、个人页和浏览器前进/后退；不伪造登录或付款成功。
- HTTP 服务提供匿名设备会话、单题上传、任务进度、取消、私有历史和授权媒体下载；默认绑定 127.0.0.1。
- 真实流程：KIE Gemini视觉模型生成结构化讲解，第二次请求复核，再调用KIE ElevenLabs配音，使用 edulab 时间轴/板书引擎与 Chromium/ffmpeg 生成 MP4。
- 无模型配置时允许明确标注的固定示例，任意上传不能返回示例冒充识题成功。示例允许 macOS 离线语音，所有付费调用默认关闭。
- 预览、生成中、结果、错误、空历史和取消状态可操作；不默认按学段拦截。

## 限制与费用

- 每题最多 2 次模型请求、总计最多 12 段配音，即最多14次收费生成调用；状态查询和下载单独限额，总HTTP请求最多171次；不自动重试。
- 模型输出最多 2400 token；复核最多 640 token；图片最多 4MB；单段配音最多 160 字；任务最多 300 秒。
- 项目每天最多 20 题、每设备每天最多 5 题、最多 200 条任务、队列最多 10 条、同时处理 1 题。数量和调用预留用 SQLite 原子持久化，重启不清零。
- 显式 LIVE_ENABLED=true 和非空的日预算/单题预算、模型/配音配置才允许真实调用。预算是保守预留控制，价格未经核实不声称账单硬封顶。
- 持久化停止开关同时影响入口和处理器；中断当前请求/子进程；恢复不重做已消费任务。运行中重启标记失败，避免重复付费。
- 不使用生产 Cloudflare Worker、Cron、alarm、付费云空间或部署；本轮实际外部模型/配音费用为零。

## 验证

测试真实 HTTP 上传/会话隔离/取消/停止与恢复/重启/重复提交/全局和设备额度/永久失败/无任务；离线生成可播放 MP4，核对音视频轨、时长和分辨率；检查移动与桌面界面。真实 AI/配音密钥、域名/主机和公开访问配置未完成时明确列为外部条件。
