# 拍题视频讲解 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. User requested direct execution in this session.

**Goal:** 交付可验证的拍题网站源码、持久化生成服务和真实离线视频示例。

**Architecture:** 同源响应式网站调用 Node24 服务；SQLite 持久化任务和总量；edulab 板书引擎负责可复现视频渲染。

**Tech Stack:** HTML/CSS/JavaScript, Node24, SQLite, Playwright, ffmpeg, edulab。

**Spec:** docs/superpowers/specs/2026-10-24-tutor-design.md

## Global Constraints

- 不改原始 skills；真实 API 默认关闭；不部署生产；保护已有文件。
- 每题最多 14 次外部调用、300 秒；每日项目20题/设备5题；队列10；项目任务200；并发1；不自动重试。
- 所有状态和额度持久化；停止同时覆盖入口与处理器；固定示例必须明确标注。

## Review Focus

- 多设备和重启不能绕过项目额度；相同幂等键不得重复生成。
- 取消和停机后，已返回的模型结果不能继续触发配音/渲染。
- 非本人任务/媒体无法访问；恶意 JSON/公式不得执行任意代码。
- 服务未配置时上传明确失败；不能把样例视频当作任意题目结果。
- 域名/隐私声明/公开访问控制尚未配置不得标记正式上线。
